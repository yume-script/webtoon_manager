네이버 아이디/비밀번호/쿠키, 디스코드, 다운로드 경로 등 세부 값은 환경설정 > 플러그인 설정 > 웹툰 다운로더 화면에서 입력합니다. 여기서는 확인 및 디스코드 테스트만 가능합니다.

실행 로그(최근)

    

  


  

    

      
⚙️ 세부 설정은 어디서 바꾸나요?

      

        네이버 아이디/비밀번호/쿠키, 다운로드 저장 경로, 자동 실행(스케줄러),
        작품당 최대 다운로드 수, 디스코드 알림, 라이브러리 자동등록 등
        모든 세부 값은 여기(카테고리탭)가 아니라
        
BookOasis 환경설정 > 플러그인 설정 > 웹툰 다운로더
        화면에서 입력합니다.
      

      

        이 카테고리탭(지금 보시는 화면)의 "설정" 탭에서는 현재 설정값 요약
        확인과 디스코드 테스트 알림 보내기만 가능하고, 값을 직접 바꿀 수는
        없습니다.
      

    

    

      
🍪 네이버 쿠키 등록 방법 (Cookie-Editor 사용법)

      

        1. 크롬 웹스토어에서 Cookie-Editor 확장 프로그램을 설치합니다.
      

      

        2. 크롬에서 comic.naver.com에 접속해 정상적으로 로그인합니다.
        성인 작품을 받으실 계획이면 이때 성인인증도 미리 완료해두세요.
      

      

        3. comic.naver.com 페이지를 보고 있는 상태에서 툴바의 Cookie-Editor
        아이콘을 클릭합니다.
      

      

        4. 창 하단(또는 우측 상단)의 Export 버튼을 누르고
        "Export as JSON"을 선택합니다 - 클립보드로 자동 복사됩니다.
      

      

        5. BookOasis 환경설정 > 플러그인 설정 > 웹툰 다운로더로 가서
        "네이버 쿠키(JSON)" 입력란에 그대로 붙여넣고 저장합니다.
        Cookie-Editor가 내보내는 형식(감싸는 객체 없는 배열 `[...]`)과
        예전 Playwright storage_state 형식(`{"cookies":[...]}`) 둘 다
        그대로 지원하니, 형식을 따로 손볼 필요 없습니다.
      

      

        ⚠️ 쿠키는 시간이 지나면 만료됩니다. 다운로드가 갑자기 실패하고
        "인증 만료"나 "성인 인증이 필요" 로그가 뜨면, 이 과정을 그대로
        반복해서 쿠키를 새로 발급받아 다시 붙여넣어 주세요.
      

    

    

      
⚠️ "이미 실행 중인 작업이 있습니다"가 계속 뜰 때

      

        BookOasis 컨테이너가 재시작되거나 스캔 도중 오류가 나면, 실제로는 아무것도
        안 도는데 상태 파일에만 "실행 중"이 남아있는 경우가 있습니다(유령 상태).
        이럴 땐 "취소" 버튼이 반응하지 않을 수 있습니다.
      

      

        아래 "작업 상태 강제 초기화" 버튼을 누르면 실행 중/취소 요청
        상태를 전부 대기 상태로 되돌립니다. 실제로 뭔가 다운로드 중이었다면
        그 작업은 중간에 끊길 수 있으니, 정말 아무것도 안 도는 것 같을 때만
        눌러주세요.
      

      
    

    

      
스캔 관련

      

        "지금 스캔"은 요일별 연재 목록만 빠르게 가져옵니다(수 초~수십 초).
        "완결 목록 수집"은 완결작 전체 목록(최대 200페이지)을 훑어서
        느립니다 - 하루 중 설정한 시각(환경설정의 "완결 전체 목록 수집 시각")에
        스케줄러가 자동으로 한 번 실행하며, 필요하면 이 버튼으로 수동 실행도
        가능합니다.
      

    

    

      
유료 회차

      

        "24시간마다 무료" 같은 로테이션 작품은 지금 유료로 잠긴 회차라도
        나중에 무료로 풀릴 수 있어 영구적으로 건너뛰지 않고 다음 스캔 때
        다시 확인합니다. "수동 다운로드" 탭에서는 유료 회차 체크박스가
        비활성화되어 선택할 수 없습니다.
      

    

    

      
📁 파일 저장 방식

      

        회차 이미지는 압축하지 않고 낱장 파일 그대로 회차 폴더 안에 저장됩니다
        (BookOasis의 imgdir 포맷). 예전 버전(zip/cbz 압축)으로 받아둔 파일이 있어도
        그대로 두면 되고, 자동으로 지워지거나 변환되지 않습니다.
