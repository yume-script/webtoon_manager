카카오페이지 작품은 [전체목록]에 네이버 작품과 함께 표시됩니다(상단 [네이버]/[카카오]로 구분). 요일별/신작 목록은 "지금 스캔"과 스케줄러의 요일별 스캔 때, 완결 목록은 완결 스캔 때 함께 수집됩니다. 로그인 계정으로 볼 수 있는 회차(무료 / 대여·소장)만 받고, 유료 구매는 하지 않습니다.

kavita.yaml

      📌 한눈에 보기
      

        웹툰 다운로더는 네이버웹툰과 카카오페이지 웹툰의 연재 목록을 모아 보여주고,
        구독한 작품의 볼 수 있는 회차(무료 회차, 이미 대여·소장한 회차, 설정에 따라 이용권으로 연 회차)를
        자동으로 받아 회차별 zip으로 저장합니다. 유료 회차를 결제(코인/캐시/쿠키 구매)하는 일은 하지 않습니다.
      

      

        전체 흐름: ① 목록 수집(스캔) → ② 구독(직접 또는 자동 구독 규칙) →
        ③ 새 회차 다운로드(스케줄러 또는 카드의 "다운로드") →
        ④ 부가 파일 생성(ComicInfo.xml / series.json / kavita.yaml).
        모든 설정은 이 화면의 [설정] 탭에서 [공통] [네이버웹툰] [카카오웹툰] [카카오웹소설]로 나눠 바꿉니다
        (BookOasis 환경설정 > 플러그인 설정 화면에는 항목이 표시되지 않습니다).
      

    


    

      🚀 처음 설정하기
      
[설정] > [공통]

      
    
        
  1. 자동 실행(스케줄러) 사용을 켜고 실행 주기를 정합니다(기본 240분, 최소 10분).
    2. 
        
  2. 저장 위치가 rclone/원격 마운트라면 임시 작업 경로를 빠른 로컬 디스크로 지정하세요(압축 전 낱장 이미지를 받는 곳).
    3. 
        
  3. Kavita/BookOasis에서 쓸 부가 파일(ComicInfo.xml, series.json, kavita.yaml)을 원하는 대로 켜고 끕니다.
    4. 
        
  4. 디스코드 알림을 받으려면 웹훅 URL(또는 봇 토큰+채널 ID)을 넣고 디스코드 테스트 알림으로 확인합니다.
    5. 
      

      
[설정] > [네이버웹툰]

      
    
        
  1. 저장 경로를 지정합니다(비우면 플러그인 데이터 폴더).
    2. 
        
  2. 성인 작품이나 대여·소장한 유료 회차를 받으려면 네이버 로그인 쿠키를 넣습니다(아래 "네이버 쿠키 등록" 참고).
    3. 
        
  3. 매일+ 작품도 받을지, 이미 갖고 있는 작품(중복 확인 폴더)도 받을지 정합니다(둘 다 기본은 받지 않음).
    4. 
      

      
[설정] > [카카오웹툰] / [카카오웹소설]

      
    
        
  1. [카카오웹툰]에서 카카오페이지 사용을 켜고 저장 경로를 지정합니다. 웹소설은 [카카오웹소설]에서 따로 켭니다.
    2. 
        
  2. 자동 실행 때 카카오도 확인하려면 자동 실행에 포함을 켭니다(기본 켜짐).
    3. 
        
  3. 무료 회차만 받을 거면 쿠키 없이도 됩니다. 성인 작품·대여권 사용·대여/소장 회차는 카카오페이지 로그인 쿠키가 필요합니다(웹툰·웹소설 공통).
    4. 
        
  4. 기다무 작품을 받을지, 이미 갖고 있는 작품도 받을지 웹툰/웹소설 각각 정합니다(기본은 받지 않음).
    5. 
        
  5. 저장 후 화면 상단 "지금 스캔(요일별)"을 한 번 눌러 목록을 채웁니다.
    6. 
      

    


    

      🍪 네이버 쿠키 등록 (Cookie-Editor)
      
    
        
  1. 크롬 웹스토어에서 Cookie-Editor 확장 프로그램을 설치합니다.
    2. 
        
  2. 크롬에서 comic.naver.com에 접속해 로그인합니다. 성인 작품을 받으려면 성인 인증까지 완료해 둡니다.
    3. 
        
  3. comic.naver.com 페이지를 연 상태에서 Cookie-Editor 아이콘 → Export → Export as JSON(클립보드에 복사됨).
    4. 
        
  4. [설정] > [네이버웹툰] > 네이버 로그인 쿠키 칸에 붙여넣고 설정 저장.
          Cookie-Editor 배열 형식([...]), Playwright storage_state 형식({"cookies":[...]}),
          개발자도구의 Cookie 헤더 문자열(NID_AUT=..; NID_SES=..) 모두 지원합니다.
    5. 
        
  5. 저장 전에 칸 아래 "쿠키 검증"을 누르면 로그인 쿠키(NID_AUT, NID_SES) 유무와,
          목록의 성인 작품 무료 회차를 실제로 열어 성인 인증 여부를 확인합니다.
          성인 인증이 확인되면 이전에 성인 인증 실패로 건너뛰던 작품들도 다시 시도됩니다.
          (네이버 성인 인증은 1년마다 갱신이 필요할 수 있습니다)
    6. 
      

      

        비밀번호/쿠키 칸은 보안상 비어 보이며 비워 두고 저장하면 기존 값이 유지됩니다(지우려면 "지우기" 체크).
        쿠키는 시간이 지나면 만료됩니다. 로그에 "인증 만료" / "로그인 페이지로 리다이렉트됨"이 보이면 같은 방법으로 다시 넣어 주세요.
      

      

        쿠키 자동 갱신: [설정] > [공통]의 간격(기본 6시간)마다, 예약 실행을 꺼 둬도 로그인 상태를 확인하며 세션을 살려 둡니다.
        네이버가 새 쿠키를 내려주면 플러그인 데이터 폴더(naver_cookie_state.json)에 저장해 다음부터 그걸 씁니다.
        네이버는 토큰 연장 API가 없어서 로그인할 때 "로그인 상태 유지"를 체크해야 쿠키가 오래 갑니다.
        로그인이 풀리면 디스코드로 한 번 알립니다. 아이디/비밀번호 자동 로그인은 하지 않습니다(캡차·2단계 인증 때문에 불안정하고 계정 보안상 위험).
      

    


    

      🟢 네이버 - 어떤 회차를 받나요?
      
    
        
  • 무료 회차: 항상 받습니다.
    • 
        
  • 유료 회차(목록에 유료 표시):
          [네이버웹툰] "대여/소장한 유료 회차도 받기"(기본 켜짐) + 네이버 쿠키가 있으면 회차를 한 번 열어 보고,
          쿠키(네이버 결제수단)로 이미 대여·소장한 회차면 받습니다. 대여·소장 안 된 회차를 만나면 그 작품은 거기서 멈추고
          다음 실행 때 다시 확인합니다(결제 없음). 쿠키가 없거나 옵션을 끄면 유료 표시 회차에서 바로 멈춥니다.
    • 
        
  • 구매한 유료 회차: 쿠키가 있으면 유료 회차도 한 회차씩 열어 보고 구매·대여한 회차는 받습니다.
          중간에 안 산 회차가 있어도 멈추지 않고 다음 유료 회차를 계속 확인하며(한 번에 최대 30개),
          하루 1번은 목록 전체에서 아직 안 받은 구매 회차를 찾아 받습니다. 선택 회차 다운로드에서도 쿠키가 있으면 유료 회차를 고를 수 있습니다.
    • 
        
  • "24시간마다 무료" 같은 로테이션: 지금 잠긴 회차도 나중에 풀릴 수 있어 영구적으로 건너뛰지 않고 다음 실행 때 다시 확인합니다.
    • 
        
  • 성인 작품: 성인 인증된 계정의 쿠키가 있어야 받습니다. 쿠키가 없으면 성인 작품은 처음부터 건너뛰고,
          쿠키가 있는데 인증에 막히면 그 작품만 건너뜁니다(같은 쿠키로는 재시도 안 함, 쿠키를 바꾸면 다시 시도).
    • 
        
  • 작품당 1회 실행 상한: [공통] "작품당 1회 실행에 받을 최대 회차 수"(기본 10화). 넘으면 카드에 UP 배지가 붙고 다음 실행 때 이어 받습니다.
    • 
        
  • 선택 회차 다운로드 탭: 원하는 회차만 골라 받을 수 있습니다(네이버·카카오 모두, 유료 회차는 선택 불가).
    • 
      

    


    

      🟢 네이버 - 목록 수집과 자동 구독
      
    
        
  • 요일별 스캔("지금 스캔" / 스케줄러): 월~일 + 매일+ 연재 목록과, [작가·태그 관리]에 등록한 태그(장르) 목록을 가져옵니다.
    • 
        
  • 완결 목록 수집: 완결작 전체(최대 200페이지)라 느려서 하루 1번, [공통] "완결 목록 수집 시각"(0~23시, 한국 시간)에 따로 돕니다.
          구독 중인 작품이 완결로 바뀌면 디스코드로 알립니다.
    • 
        
  • 관심 작가: [작가·태그 관리]에 등록한 작가의 작품은 처음 발견될 때 자동 구독됩니다.
    • 
        
  • 신간 자동 구독([공통]): 목록에 처음 나타나는 작품을 모두 자동 구독. 설치 직후 첫 스캔에는 적용하지 않습니다(전 작품 일괄 구독 방지).
    • 
        
  • 매일+ 작품 받기([네이버웹툰], 기본 꺼짐): 켜면 매일+ 탭 작품을 전부 자동 구독해 받습니다. 끄면 매일+ 작품은 받지 않고,
          예전에 자동 구독된 매일+ 작품도 구독 전 상태로 되돌립니다. 직접 구독한 작품은 설정과 상관없이 받습니다.
    • 
        
  • 이미 갖고 있는 작품도 받기(플랫폼 탭마다, 기본 꺼짐): 끄면 중복 확인 폴더/라이브러리에 같은 이름이 있는 작품은 자동 다운로드에서 뺍니다.
          이 플러그인이 이미 받기 시작한 작품과 카드의 "다운로드" 버튼은 예외입니다.
    • 
        
  • 자동 구독 규칙은 사용자가 한 번도 구독/구독해제/제외를 고르지 않은 작품에만 적용됩니다. 직접 고른 선택이 항상 우선입니다.
    • 
        
  • BL / GL 장르: [설정] > [공통] "BL 장르 받기" / "GL 장르 받기"가 꺼져 있으면(기본) 네이버·카카오 모두 해당 장르 작품은

      🔢 카카오 회차 파일 번호(9000번대)란?
      

        카카오 회차 파일 번호는 회차 제목의 "N화" 번호를 따릅니다(예: "철혈검가 사냥개의 회귀 3화" → 0003화).
        회차 제목에 "N화"가 없는 프롤로그 / 외전 / 후기 / 특별편 / 동영상 트레일러, 그리고 앞 회차와 번호가
        겹치는 회차(시즌2가 1화부터 다시 시작 등)는 본편과 섞이지 않도록 9000 + 사이트 순번으로 저장합니다
        (예: 사이트의 첫 번째 회차인 프롤로그 → 9001화). 그래서 Kavita에서는 본편 뒤에 정렬됩니다.
      

      

        어떤 9000번대 파일이 무슨 회차인지는 시리즈 폴더의 특별회차_목록.txt에 9001화 = 프롤로그처럼 기록되고,
        zip 안의 ComicInfo.xml 제목에도 실제 회차 제목이 들어갑니다. 로그에는 "특별회차(사이트 N번째 회차, 파일 9001화)"로 표시됩니다.
        예전 버전(사이트 순번으로 번호를 매기던 1.18.4 이하)으로 받은 파일은 작품을 다음에 확인할 때 자동으로 새 번호로 이름이 바뀝니다.

      ⚡ 다운로드 속도
      
    
        
  • 네이버와 카카오는 동시에 받습니다(서로 다른 사이트라 차단 위험이 늘지 않음).
    • 
        
  • 고속 모드([공통] > 다운로드 속도, 기본 꺼짐): 밀린 회차를 몰아받을 때 켜세요. 동시 작품 6개 이상, 이미지 10개 이상,
          회차 간 대기 0.2초 이하, 작품당 1회 50화까지로 올립니다(이미 더 높게 잡아 둔 값은 그대로). 다 따라잡으면 꺼도 됩니다.
    • 
        
  • 자동 속도 조절: 서버가 "요청이 너무 많다"(429)나 일시 장애(503)를 돌려주면 그 사이트 전체가 2초부터 두 배씩(최대 2분) 쉬었다가
          다시 시도하고, 정상 응답이 이어지면 다시 빨라집니다. 상단 진행 줄에 "서버 제한으로 N초 쉬는 중 / 속도 조절 N단계"로 보입니다.
          속도 조절이 자주 보이면 동시 작품 수를 줄이세요.
    • 
        
  • 최근 1시간 N화: 상단 진행 줄 아래에 실제 다운로드 속도(네이버/카카오별)가 표시됩니다. 설정을 바꾼 뒤 이 숫자로 효과를 확인하세요.
    • 
        
  • 동시에 처리할 작품 수([공통], 기본 2, 최대 10): 네이버·카카오 각각 작품 여러 개를 나란히 처리합니다.
          작품 안에서는 "이미지 동시 다운로드 수"만큼 이미지를 동시에 받으므로, 실제 동시 요청 수는 대략 작품 수 × 이미지 수입니다.
    • 
        
  • zip 저장은 백그라운드: 회차 zip은 로컬 임시 폴더에서 만들고 라이브러리(원격 마운트일 수 있음)로는 별도 스레드가 옮깁니다.
          그동안 다음 회차를 바로 받습니다. 옮기기 실패나 중단으로 남은 zip은 임시 폴더의 _outbox에 있다가 다음 실행 때 다시 옮겨집니다.
    • 
        
  • 새로 구독한 작품은 최신 N화만 받기([공통], 기본 0 = 전체): 기다무 작품 받기처럼 한꺼번에 많은 작품이 들어올 때
          첫 다운로드 양을 크게 줄입니다. 그 이전 회차는 받지 않으며, 필요하면 카드의 "다운로드"(카카오) 또는
          "다시 확인"(네이버·카카오), backfill_all.py(네이버)로 전부 받을 수 있습니다.
    • 
        
  • 작품당 상한("작품당 최대 신규 다운로드")에 걸려도 더 이상 쉬지 않고 바로 다음 작품으로 넘어갑니다(남은 회차는 다음 실행 때).
    • 
        
  • 저장 경로가 rclone 마운트라면 임시 작업 경로는 로컬 디스크로 지정하고, 마운트에 --vfs-cache-mode writes를 켜 두면
          zip을 옮길 때 업로드 완료를 기다리지 않습니다.
    • 
      

    


    

      🗂️ 목록 화면과 카드 버튼
      
    
        
  • 탭: 전체목록 / 구독중 / 구독해제 / 제외됨 / 중복(이미 라이브러리에 있는 작품).
    • 
        
  • 플랫폼 필터: [전체] [네이버웹툰] [카카오웹툰] [카카오웹소설]. 카드의 초록 네이버 / 노란 카카오 배지로도 구분됩니다.
    • 
        
  • 요일 필터: [신작] [월]~[일] [매일+](네이버) [기다무](카카오, 연재 중) [완결].
    • 
        
  • 카드는 120장씩 표시되고 맨 아래 "더 보기"로 이어서 봅니다.
    • 
        
  • 배지: 신작 / 완결 / 휴재 / UP(이번 실행 상한에 걸려 남은 회차가 있음) / 기다무 / 19 / 웹소설 / BL·GL.
    • 
        
  • 구독 · 다시 구독: 자동 다운로드 대상에 넣습니다.
    • 
        
  • 새회차 다운로드: 그 작품의 받을 수 있는 회차를 지금 받습니다(카카오는 볼 수 있는 미보유 회차 전부). 다른 작품을 받는 중이면 대기열에 들어가 차례로 받습니다(상태 줄에 "대기 N개").
          끝나면 상태 줄에 2분간 ✅/❌ 결과가 남고, 카드에 "마지막 확인 결과"가 표시됩니다.
    • 
        
  • 다시 확인: 그 작품의 "어디까지 확인했는지" 기록을 지워 다음 다운로드 때 처음부터 다시 봅니다(이미 있는 파일은 건너뜀).
    • 
        
  • 구독해제: 자동 다운로드에서 뺍니다. 제외: 목록에서 숨기고 자동 구독 규칙도 적용하지 않습니다.
    • 
        
  • 선택 회차 다운로드(네이버·카카오): 회차 목록에서 원하는 회차를 골라 받습니다(이미 받은 회차를 고르면 지우고 다시 받음).
          탭에서 [네이버]/[카카오]를 고르고 titleId 또는 카카오 작품 번호/URL로 직접 조회할 수도 있습니다. 열기: 네이버웹툰 / 카카오페이지의 작품 페이지를 새 탭으로 엽니다.
    • 
      

    


    

      📁 저장되는 파일
      
    
        
  • 폴더: 저장 경로/제목 (작품번호)/ - 네이버는 titleId, 카카오는 series_id. 네이버/카카오 저장 경로는 따로 지정합니다.
    • 
        
  • 회차 파일: 제목 0022화#110.zip(#뒤는 이미지 장수). 하위 폴더 없이 시리즈 폴더에 바로 저장됩니다.
    • 
        
  • 받는 과정: 임시 작업 경로에 낱장 이미지를 모두 받은 뒤 압축해서 옮깁니다. 미완성 파일이 라이브러리에 노출되지 않습니다.
          "zip 무압축 저장"(기본)은 이미지 재압축을 하지 않아 CPU를 아낍니다.
    • 
        
  • 표지 첫 페이지: 켜면 각 zip의 첫 장에 작품 표지를 넣습니다.
    • 
        
  • ComicInfo.xml(zip 안): 작품명·회차 제목·작가·장르 등.
    • 
        
  • series.json: BookOasis 스캐너용 작품 정보.
    • 
        
  • kavita.yaml: action / files / meta / search 형식. code는 네이버 BNW<titleId>, 카카오 KKP<series_id>.
          회차가 추가되거나 작품 정보(완결 등)가 바뀔 때 갱신되고, 내용이 같으면 파일을 건드리지 않습니다.
          [설정] 탭의 "전체 작품 kavita.yaml 생성/갱신"으로 한 번에 만들 수 있습니다.
    • 
        
  • 특별회차_목록.txt(카카오): 9000번대 회차가 무엇인지 안내.
    • 
      

    


    

      🔔 디스코드 알림
      
    
        
  • 완결 감지: 구독 작품이 완결로 바뀌면 알림.
    • 
        
  • 쿠키 만료: 네이버/카카오 쿠키 만료 감지 시 알림(카카오는 만료될 때마다 1번만).
    • 
        
  • 다운로드 실패 요약: 실행 중 실패한 회차 목록(최대 20건).
    • 
      

    


    

      ⏬ 서버에서 직접 실행하는 스크립트
      
backfill_all.py - 네이버 구독작의 과거 회차까지 한 번에 받기(이미 받은 회차는 건너뜀).
        카카오는 카드의 "다운로드" 버튼이 같은 역할(받을 수 있는 회차 전부)을 합니다.

      

        docker exec -it bookoasis python3 /app/plugins/metadata/webtoon_manager/backfill_all.py --dry-run
      

      

        확인 후 --dry-run을 빼고 실행. 옵션: --title-id 808389(특정 작품, 여러 번 가능) /
        --limit-per-title 50 / --max-titles 10 / --delay 2 /
        --include-unsubscribed / --db-type adult.
        실행 중에는 작업 잠금을 잡아 스케줄러와 겹치지 않고, 카테고리탭의 "취소"나 Ctrl+C로 멈춰도 다음 실행 때 이어 받습니다.
      

      
migrate_filenames.py - 예전 형식(낱장 폴더 / 숫자만 있는 .cbz / 제목 없는 "N화#장수" / 공백 구분)으로 받아둔 파일을
        지금 형식으로 정리(중복은 삭제, 나머지는 이미지 손실 없이 이름 변경/압축).

      

        docker exec -it bookoasis python3 /app/plugins/metadata/webtoon_manager/migrate_filenames.py "다운로드_저장_경로" --dry-run
      

    


    

      🛠️ 문제 해결
      
    
        
  • 다운로드를 눌러도 안 받아져요: 상태 줄의 결과(✅/❌)와 카드의 "마지막 확인 결과", [설정] 탭 아래 로그의
          "카카오 다운로드 시작…" 이후 줄을 확인하세요. 다른 작품을 받는 중이면 대기열에 들어가 있을 수 있습니다.
    • 
        
  • "유료라 건너뜀"이 많아요: 정상입니다. 무료가 끝난 뒤 유료 회차는 요청하지 않고 건너뜁니다.
          대여권으로 받으려면 [카카오웹툰] 대여권 옵션을 켜세요.
    • 
        
  • 성인 작품이 안 받아져요: 카카오는 [설정]의 "쿠키 검증"에서 성인 인증 ✅인지 확인하세요.
          네이버는 성인 인증을 마친 계정으로 쿠키를 다시 내보내 넣으세요.
    • 
        
  • kavita.yaml이 없는 폴더가 있어요: 폴더 안에 회차 zip이 없거나, 폴더명이 "제목 (번호)" 형식이 아니면 만들지 않습니다(로그에 "형식불일치").
    • 
        
  • 업데이트 배지가 이상해요: GitHub 저장소의 VERSION이 설치된 버전보다 높을 때만 표시됩니다.
    • 
        
  • "이미 실행 중인 작업이 있습니다"가 계속 떠요: 컨테이너 재시작 등으로 상태 파일에만 "실행 중"이 남은 경우입니다.
          작품 단위 다운로드는 15분 넘게 진행이 없으면 자동으로 풀립니다. 전체 작업이 굳었으면 아래 버튼을 누르세요
          (실제로 돌고 있던 작업은 중간에 끊길 수 있으니 아무것도 안 돌 때만).
